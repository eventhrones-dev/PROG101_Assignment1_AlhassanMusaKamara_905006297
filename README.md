# PROG101_Assignment1_AlhassanMusaKamara_905006297
 Problem
Flooding in Freetown communities such as Kroo Bay and Wellington causes loss of life and property each rainy season. Warnings are slow and informal.

Solution
A logical design for an open-source system that takes rainfall, river level and blocked-drain information, calculates a risk score, classifies the risk (LOW, MODERATE, HIGH, SEVERE) and says if evacuation is needed.
